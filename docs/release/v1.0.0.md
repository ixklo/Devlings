# v1.0.0 release gates

Each gate is green only with public evidence: a CI run, a release URL, a commit SHA or a one-line QA result. A *(waivable)* gate can ship unmet only if the reason is recorded here and in the release notes.

Status: ⬜ open · 🟡 in progress · ✅ green · ⚠️ waived

**Result: every gate green. [Perch v1.0.0](https://github.com/yeetstick/perch/releases/tag/v1.0.0) is published as Latest.**

Live QA ran on Windows 11 (one 2880×1800 display at 200%) with Claude Code 2.1.282, then 2.1.283 (the VS Code extension updated itself during QA). Perch's own windows were driven through Windows UI Automation and, for drag and the right-click menu, through mouse and key messages posted to Perch's windows only; tiny headless `claude -p` runs stood in for sessions. Four release candidates were published and QA'd; each one's fixes are linked below.
