Perch

A pixel-art desktop pet for Claude Code. See every session at a glance, answer permission prompts and ask Claude Code something, right from your desktop.

What it does

Watch every session

Every Claude Code session, in VS Code, a terminal or the desktop app, shows up as a card above the pet: running, needs input, ready or blocked. The pet reacts along with it, a card pops up when a session finishes or needs you, and a click takes you back to the project.

Ask from the pet

Click the pet, pick a project folder and type. Perch runs your own Claude Code in that folder and streams the answer into a small chat above the pet. Follow-ups continue the same conversation.

Answer permission prompts

When Claude Code wants to run a command or edit a file, Allow or Deny it from a card that shows the exact command, file or URL. Nothing is pre-selected and no key answers a card, so a stray Enter never approves anything.

Updates itself

Perch checks for a new release at launch and once a day, and installs signed updates in the app, so there's no installer to download again. You can turn this off in Settings.

Pick a pet

Three pets are built in, and you can name yours. Perch also reads pets in the Codex pet format, so you can draw your own.

How it works

  1. Claude Code's hooks, on your machine. With your OK, Perch adds a few hooks to Claude Code's settings.json. Each session then reports its progress to Perch over 127.0.0.1; if Perch isn't running, the hooks fail fast and silently. A backup is kept before every change, and one click removes exactly Perch's entries.
  2. Your own Claude Code, on your own subscription. When you ask from the pet, Perch runs the Claude Code you already have, logged in with your Claude plan. It never uses an API key and has no login of its own.
  3. Everything else stays out of the way. The area around the pet is click-through, so the window never blocks what's behind it.

Privacy

Perch sends nothing anywhere itself except hook events and permission answers on 127.0.0.1, which never leave your machine, and a daily check for a newer version on GitHub, which you can turn off. Your prompts go to Anthropic through your own Claude Code, exactly as they would from a terminal. On Windows, Microsoft's WebView2 runtime makes its own connections to Microsoft, as it does for every app built on it. This page loads no scripts, fonts or trackers. More detail.

Questions

Is it free?

Yes. Perch is free and open source under the MIT license, with no paid tier and no account.

Which operating systems does it run on?

Windows 11 is verified. macOS (Apple Silicon and Intel) and Linux (AppImage and .deb) are in beta: the installers build and launch in CI on every change but haven't been tested on real hardware yet. Windows 10 isn't tested yet. You also need Claude Code 2.1.259 or newer, logged in with a Claude subscription (Pro, Max, Team or Enterprise).

Will Windows warn me when I install it?

Yes, the first time. The installers aren't signed with a paid certificate, so SmartScreen says "Windows protected your PC": click More info, then Run anyway. On macOS, open System Settings → Privacy & Security and click Open Anyway. Install steps for every system.

What does it cost to use?

Watching is free: Perch only listens to Claude Code's hooks, so no prompts are sent. Asking from the pet runs your own Claude Code in non-interactive mode, which draws on the monthly Agent SDK credit that comes with paid Claude plans. Perch never uses an API key, and it stops a run the moment Claude Code reports it would start using paid usage credits. How Asks are counted.
